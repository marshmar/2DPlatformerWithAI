// 좌표: 맨 아래 줄이 y = 0, 맨 왼쪽 글자가 x = 0 (타일 1칸 = 1유닛). 월드 위치 = 칸 + @origin
// 지형:  # 지형   H 갈고리가 걸리는 지형   = 갈고리가 걸리는 철골   ^ 전기 바닥(닿으면 피해 + 마지막 안전 발판으로)   . 빈칸
// 배치:  P 시작 위치   E 근접 적(Punk)   T 터렛   D 드론   G 출구 포털(3x4, 이 칸이 왼쪽 아래)
//        K 체크포인트(바닥 위 칸)   o 데이터 칩   | 아레나 게이트(세로로 이어 쓴다. 같은 @room 의 적을 모두 쓰러뜨리면 열린다)
// 연출:  m / c / a 네온 라이트(마젠타/시안/앰버)   n 네온 간판(세로 3칸, 지형 맨 윗칸보다 2칸 위에 찍으면 바닥에 선다)   ~ 물웅덩이(지형 윗면 바로 위 칸)
// 지시어: @name 섹터 코드   @subtitle 섹터 이름   @origin x y   @room x0 y0 x1 y1 (카메라 방)   @ambient r g b [배경 r g b]   @hint x0 y0 x1 y1 안내 문구
// 방: 1 하강 → 2 전기 수로 → 3 수직 통로 → 4 봉쇄 아레나 → 5 갈고리 협곡 → 6 출구

@room 60 0 124 46
@hint 60 6 75 16 넓은 틈은 갈고리로 · 매달린 채 [SHIFT] 를 누르면 고정점으로 감겨 날아간다
@room 124 0 170 46
@hint 136 6 148 20 벽에 붙어 [SPACE] — 양쪽 벽을 번갈아 차며 올라간다
@room 170 0 236 46
@room 236 0 302 46
@room 302 0 332 46
