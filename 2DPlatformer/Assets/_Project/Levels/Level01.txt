// 좌표: 맨 아래 줄이 y = 0, 맨 왼쪽 글자가 x = 0 (타일 1칸 = 1유닛). 월드 위치 = 칸 + @origin
// 지형:  # 지형   H 갈고리가 걸리는 지형   = 갈고리가 걸리는 철골   ^ 전기 바닥(닿으면 피해 + 마지막 안전 발판으로)   . 빈칸
// 배치:  P 시작 위치   E 근접 적(Punk)   T 터렛   D 드론   G 출구 포털(3x4, 이 칸이 왼쪽 아래)
//        K 체크포인트(바닥 위 칸)   o 데이터 칩   | 아레나 게이트(세로로 이어 쓴다. 같은 @room 의 적을 모두 쓰러뜨리면 열린다)
// 연출:  m / c / a 네온 라이트(마젠타/시안/앰버)   n 네온 간판(세로 3칸, 지형 맨 윗칸보다 2칸 위에 찍으면 바닥에 선다)   ~ 물웅덩이(지형 윗면 바로 위 칸)
// 지시어: @name 섹터 코드   @subtitle 섹터 이름   @origin x y   @room x0 y0 x1 y1 (카메라 방)   @ambient r g b [배경 r g b]   @hint x0 y0 x1 y1 안내 문구
// 방: 1 옥상 → 2 수직 통로 → 3 갈고리 협곡 → 4 아레나(봉쇄) → 5 출구

@subtitle 네온 옥상
@origin -20 -8
@room 0 0 64 26
@room 64 0 104 51
@room 104 0 172 51
@room 172 0 226 41
@room 226 0 262 31
@hint 3 4 12 12 [A / D] 이동    [SPACE] 점프 — 길게 누르면 더 높이 뛴다
@hint 12 4 20 12 [마우스 왼쪽] 청록색 블록에 갈고리 — 누르고 있으면 매달리고, 떼면 날아간다
@hint 24 4 34 10 전기 바닥에 닿으면 피해를 입고 마지막으로 서 있던 곳으로 돌아간다
@hint 44 6 60 14 [마우스 오른쪽] 공격 (3연타)  ·  적에게 갈고리를 걸면 날아가 처형한다
@hint 70 6 82 16 벽 쪽으로 붙은 채 [SPACE] — 양쪽 벽을 번갈아 차며 올라간다
@hint 100 37 112 44 매달린 채 [SHIFT] — 고정점으로 감겨 날아간다 (감기 대시)
@hint 172 6 182 16 봉쇄 구역 — 이 구역의 적을 모두 쓰러뜨리면 게이트가 열린다
